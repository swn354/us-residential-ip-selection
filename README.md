## 四个词先分清：住宅 IP、原生 IP、双 ISP、家宽 VDS

这四个词经常被混着用，实际指向不同的东西，选错产品线钱就白花了。

**住宅 IP** 强调的是 IP 归属方。归属是 AT&T、Comcast、Frontier、Astound Broadband 这类家庭宽带 ISP，平台就认为这是家庭用户；归属是数据中心，再干净的段也会被打上机房标记。

**原生 IP** 强调注册地和机器实际所在地一致。美国机房给的就是真正的美国 IP，不是拿别国 IP 套一层美国 CDN。做美区业务时这条是底线，否则 IP 归属地和你声称的身份对不上，风控照样抓。

**双 ISP** 指这个 IP 在数据库里同时带两个 ISP 属性标记，可信度比单 ISP 高一档。多数跨境业务说的"双 ISP 住宅 IP"就是这个层级，机器还是托管在机房里，只是 IP 段被标记为家宽属性。

**家宽 VDS** 是另一回事：设备直接托管在美国真实民房里，走当地家庭宽带线路，资料里列的是西雅图 Atlas Networks、加州 Astound Broadband、加州 T-Mobile/Frontier。IP 质量比机房里的"住宅属性 IP"再高一档，代价是带宽和流量限制更接近真实家宽，价格也贵一倍左右。

一句话区分：前三个是"IP 看起来像住宅"，最后一个是"机器真的住在住宅里"。绝大多数账号问题在双 ISP 这层就能解决，只有对 IP 极度敏感的业务才需要往上加钱。

## 哪些人不适合买，哪些限制要先接受

**家宽 VDS 和 NAT 都不享受 48 小时无条件退款**。年付能省不少，但先月付跑一周更稳妥。

**NAT 共享版的限制最硬**：共享 1 个 IPv4、只给 2 到 10 个端口、CN2 GIA 峰值禁止长时间占用、手动开通要等 24 小时、无退款。拿它养主号，等于把账号安全交给同机的陌生人。

**带宽是峰值，不等于持续带宽**。流量统计口径也不一样：家宽 VDS 是单向月流量，NAT 是双向，9929 和 4837 是月流量配额。买之前按自己的月消耗算一遍。

**住宅 IP 不是免风控的通行证**。IP 只解决"平台认为你是谁"这层，登录设备、操作频率、内容合规同样影响结果。

**这几类需求不该买**：大流量代理分发（带宽和流量配比不划算）、重负载计算和高并发（这机器定位是 IP 和线路优先）、低延迟游戏（中美物理延迟摆在那，优化也快不到哪去）。
